# EventFlow
Application web de gestion d'événements (projet académique, binôme).
## Fonctionnalités
- Gestion des événements (ajout, suppression)
- Réservations avec contrôle des places et calcul du montant
- Annulation de réservation (places libérées)
## Technologies
Python 3.10+, Flask, SQLite, HTML/CSS, pytest, Git/GitHub.
## Installation
1. python -m venv .venv puis activer l'environnement
2. pip install -r requirements.txt
3. python seed.py (données de démonstration, une seule fois)
4. python app.py puis ouvrir http://127.0.0.1:5000
